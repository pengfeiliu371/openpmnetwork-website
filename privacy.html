Public website

Privacy

This page describes the public project website at www.openpmnetwork.org. The sensor data portal will publish a separate, more detailed policy before accepting external users.

What this website collects

This is a static informational website hosted with GitHub Pages. Open PM Network does not currently run analytics, advertising, user accounts, contact forms, cookies, or browser storage on this site.

GitHub may process technical information such as visitor IP addresses for security and service operation. See the GitHub Privacy Statement for its practices.

Sensor and location data

This public website does not expose device credentials, private coordinates, Wi-Fi information, source IP addresses, or unapproved sensor records. Public sensor data will be released only through an approved deployment publication with a deliberately selected public location and location accuracy.

Children and classroom use

The first K–12 design does not require student accounts and is not intended to collect student names, email addresses, classroom rosters, assignment records, comments, or profiles. Teachers or school staff will manage devices. Any later feature involving student accounts will require a separate privacy and governance review before launch.

Research and educational limits

Open PM Network measurements are intended for research and education. They are not regulatory measurements, emergency warnings, medical advice, or a substitute for official air-quality information.

Questions

Questions about this public website can be raised in the website repository issue tracker. Do not include private coordinates, credentials, student information, or other sensitive data in a public issue.
